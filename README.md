## Tools & Utilities

### SketchUp Attribute Helper
A Ruby utility module for managing entity attributes in SketchUp models. [Learn more](ATTRIBUTE_HELPER_README.md)

Features:
- Safe attribute access with default values
- Bulk operations and batch processing
- Attribute copying between entities
- Search and debugging utilities
